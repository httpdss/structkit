# Installation Guide

## Using pip

Install StructKit with pip:

```sh
pip install structkit
```

!!! tip "Enable Auto-Completion"
    After installation, enable command-line auto-completion using static scripts generated by shtab. See the [Command-Line Completion](completion.md) guide for per-shell instructions.

## Using Homebrew

StructKit is published through the [`httpdss/homebrew-structkit`](https://github.com/httpdss/homebrew-structkit) tap (formula name: `structkit`). It is not a core Homebrew formula.

```sh
brew install httpdss/structkit/structkit
```

Equivalent two-step form:

```sh
brew tap httpdss/structkit
brew install structkit
```

```sh
structkit --help
```

## Using Docker

Run StructKit without installing, using Docker:

```sh
docker run -v $(pwd):/workdir -u $(id -u):$(id -g) ghcr.io/httpdss/structkit:main generate file:///workdir/examples/python-cli/.structkit.yaml /workdir/example_output
```

Refer to the [Quick Start](quickstart.md) guide for more options.

## Linux packages (.deb / .rpm)

Native `.deb` (Debian/Ubuntu) and `.rpm` (Fedora/RHEL) packages are built by the [`build-linux-packages`](https://github.com/httpdss/structkit/actions/workflows/build-linux-packages.yaml) GitHub Actions workflow on each published release and on manual workflow dispatch. They are uploaded as **Actions workflow artifacts** (90-day retention). They are **not** attached to GitHub Releases.

To install a release package:

1. Open the [build-linux-packages workflow runs](https://github.com/httpdss/structkit/actions/workflows/build-linux-packages.yaml) and select the run for the release you want.
2. Download the artifact for your architecture:
   - `structkit-VERSION-amd64-deb` / `structkit-VERSION-arm64-deb`
   - `structkit-VERSION-amd64-rpm` / `structkit-VERSION-arm64-rpm`
3. Install from the downloaded file.

Debian/Ubuntu:

```sh
sudo dpkg -i structkit_VERSION_amd64.deb
# if needed: sudo apt-get install -f
```

Fedora/RHEL:

```sh
sudo dnf install ./structkit-VERSION-1.x86_64.rpm
# or: sudo rpm -ivh structkit-VERSION-1.x86_64.rpm
```

To build packages locally instead, follow [packaging/README.md](../packaging/README.md).
