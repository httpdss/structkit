# Installation Guide

## Using pip

Install StructKit with pip:

```sh
pip install structkit
```

!!! tip "Enable Auto-Completion"
    After installation, enable command-line auto-completion using static scripts generated by shtab. See the [Command-Line Completion](completion.md) guide for per-shell instructions.

## Using Homebrew

StructKit is published through the [`httpdss/homebrew-structkit`](https://github.com/httpdss/homebrew-structkit) tap (formula name: `structkit`). It is not a core Homebrew formula.

```sh
brew install httpdss/structkit/structkit
```

Equivalent two-step form:

```sh
brew tap httpdss/structkit
brew install structkit
```

```sh
structkit --help
```

## Using Docker

Run StructKit without installing, using Docker:

```sh
docker run -v $(pwd):/workdir -u $(id -u):$(id -g) ghcr.io/httpdss/structkit:main generate file:///workdir/examples/python-cli/.structkit.yaml /workdir/example_output
```

Refer to the [Quick Start](quickstart.md) guide for more options.

## Linux packages (.deb / .rpm)

Native `.deb` (Debian/Ubuntu) and `.rpm` (Fedora/RHEL) packages are attached to each [GitHub Release](https://github.com/httpdss/structkit/releases) starting with **3.3.1**. The [`build-linux-packages`](https://github.com/httpdss/structkit/actions/workflows/build-linux-packages.yaml) workflow builds them on every published release (and on manual `workflow_dispatch` with a tag) and uploads them to that release. A `SHA256SUMS` file is published alongside the packages. The same files are also kept as Actions artifacts (90-day retention).

Asset names include the version and architecture, for example:

- `structkit_3.3.1_amd64.deb` / `structkit_3.3.1_arm64.deb`
- `structkit-3.3.1-1.x86_64.rpm` / `structkit-3.3.1-1.aarch64.rpm`

Debian/Ubuntu (amd64):

```sh
curl -fsSL -o structkit_3.3.1_amd64.deb \
  https://github.com/httpdss/structkit/releases/download/v3.3.1/structkit_3.3.1_amd64.deb
sudo apt install ./structkit_3.3.1_amd64.deb
```

Fedora/RHEL (x86_64):

```sh
curl -fsSL -o structkit-3.3.1-1.x86_64.rpm \
  https://github.com/httpdss/structkit/releases/download/v3.3.1/structkit-3.3.1-1.x86_64.rpm
sudo dnf install ./structkit-3.3.1-1.x86_64.rpm
```

For arm64, download `structkit_3.3.1_arm64.deb` or `structkit-3.3.1-1.aarch64.rpm` from the same release URL and install the local file the same way. Replace `3.3.1` / `v3.3.1` with the version you want.

To build packages locally instead, follow [packaging/README.md](https://github.com/httpdss/structkit/blob/main/packaging/README.md).

## GitHub Actions

To run arbitrary StructKit commands in CI, install with [`httpdss/structkit-setup`](https://github.com/httpdss/structkit-setup):

```yaml
- uses: httpdss/structkit-setup@v0
- run: structkit list
```

To validate or generate as a dedicated step, call setup first, then [`httpdss/structkit-action`](https://github.com/httpdss/structkit-action). The action does not install StructKit itself:

```yaml
- uses: httpdss/structkit-setup@v0
- uses: httpdss/structkit-action@v0
  with:
    command: validate
```

See [GitHub Integration](github-integration.md) for full workflow examples.
